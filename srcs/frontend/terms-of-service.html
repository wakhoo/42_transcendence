2. Description of Service

DrawDraw is a web-based platform that provides:

  • A real-time multiplayer drawing-and-guessing game — one player receives a keyword and draws it, other players guess it in the chat
  • Remote multiplayer matches with 2 or more players and live reconnection support
  • User accounts with email/password login, Google OAuth, and optional two-factor authentication (2FA)
  • User profiles, match history, a friends list, and online status
  • Real-time chat
